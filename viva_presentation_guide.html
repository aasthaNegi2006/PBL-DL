Neural Network Architecture & Mathematical Design
What to say:
"Sign language gestures are dynamic spatio-temporal actions lasting 2 to 4 seconds. A 2D CNN alone cannot capture motion trajectories, while full 3D CNNs (like C3D or SlowFast) have tens of millions of parameters and are too computationally expensive for real-time CPU deployment.
We designed a hierarchical Spatio-Temporal ConvNet + Bidirectional GRU with Temporal Attention:
  1. Uniform Temporal Sampling: We uniformly sample 16 frames across each gesture sequence at 112x112 resolution.
  2. Spatial Feature Extractor: A 4-stage residual convolutional network with Batch Normalization and ReLU that transforms each frame into a rich 256-dimensional spatial descriptor.
  3. Temporal Sequence Modeling: A 2-layer Bidirectional Gated Recurrent Unit (BiGRU) with 128 hidden units per direction (256 combined). The bidirectional recurrence captures both forward motion and retraction dynamics.
  4. Temporal Attention Layer: Because the critical stroke of an emergency sign occurs during peak impact (e.g., fist colliding with palm in 'accident' or wrist contact in 'doctor'), the attention layer computes dynamic softmax weights over all 16 timesteps, weighting the decisive moments.
  5. Regularization & Loss: We optimize Cross-Entropy Loss with 0.05 Label Smoothing using AdamW (weight decay 1e-3) and a Cosine Annealing learning rate schedule."

Technical Viva Voce Defense (25 High-Yield Questions)

These questions directly test the competencies specified in the Semester V evaluation guidelines: mathematical depth, implementation ownership, split validity, and failure analysis.

Math Q1: Can you mathematically explain how a GRU cell updates its hidden state?
A Gated Recurrent Unit (GRU) solves the vanishing gradient problem in standard RNNs using two gates: the Reset gate ($r_t$) and the Update gate ($z_t$):
1. $r_t = \sigma(W_r x_t + U_r h_{t-1} + b_r)$ — Controls how much of the past memory to forget.
2. $z_t = \sigma(W_z x_t + U_z h_{t-1} + b_z)$ — Acts like the forget and input gate in LSTM, balancing old and new information.
3. $\tilde{h}_t = \tanh(W_h x_t + U_h (r_t \odot h_{t-1}) + b_h)$ — Candidate hidden state using the reset memory.
4. $h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$ — Final linear interpolation between old state and candidate state.
Advantage over LSTM: GRU has only 3 sets of matrix multiplications instead of 4, reducing trainable parameters by 25% and training significantly faster on CPU.
Math Q2: What is the mathematical formulation of the Temporal Attention layer?
Given the sequence of hidden states from the BiGRU: $\{h_1, h_2, \dots, h_T\}$ where $h_t \in \mathbb{R}^{2 \times \text{hidden\_dim}}$:
1. A learned feedforward scoring network computes unnormalized attention energies: $e_t = w^T \tanh(W_a h_t + b_a)$.
2. The attention weights $\alpha_t$ are normalized across time using Softmax: $\alpha_t = \frac{\exp(e_t)}{\sum_{j=1}^T \exp(e_j)}$, where $\sum_{t=1}^T \alpha_t = 1$.
3. The aggregated context vector is the weighted linear combination: $c = \sum_{t=1}^T \alpha_t h_t$.
Why this matters: In signs like 'accident', the collision occurs at frame 10-12. The attention layer automatically learns to assign peak weight $\alpha_{10..12}$ to the collision moment rather than resting frames.
Integrity Q3: Why did your initial model show 100% accuracy, and why is that invalid?
The dataset has 26 signers, each performing 2 takes per word (001_01 and 001_02). In an unconstrained random 80/20 train/test split, Take 1 of Signer 1 ended up in the training set, while Take 2 of Signer 1 ended up in the validation set.
Because both takes were recorded in the exact same studio with the identical shirt, lighting, skin tone, and backdrop, the network didn't just learn the sign; it memorized the signer's identity and clothes.
Defensible fix: We instituted a strict Signer-Independent Split (holding out signers 022 to 026 entirely) and 5-Fold Group Cross-Validation where no signer ever appears in both training and evaluation. The resulting score is honest and scientifically valid.
Engineering Q4: Why did you add a 'none' class using 'hot', 'lose', and 'thief'?
In standard 5-class classification, the final layer uses a Softmax function where probabilities must sum to 1.0 ($\sum_{i=1}^5 P_i = 1$). If an emergency system only knows 5 emergency words, then whenever a user scratches their nose, waves, or rests, the network is mathematically forced to pick one of the 5 emergency words.
By training the network on a 6th class—none—using 152 video clips of non-emergency signs (hot, lose, thief), the network learns what general hand movement looks like that is not an emergency, suppressing false alarms.
Optimization Q5: Why did you use AdamW with Cosine Annealing instead of standard SGD or Adam?
1. AdamW vs Adam: Standard Adam applies $L_2$ regularization to the gradient calculation ($g_t = \nabla \mathcal{L} + \lambda \theta$), which leads to suboptimal weight decay in adaptive methods. AdamW decouples weight decay directly into the parameter update step ($\theta_{t+1} = \theta_t - \eta_t \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon} - \eta_t \lambda \theta_t$), providing superior generalization and preventing overfitting.
2. Cosine Annealing: The learning rate follows a half-cosine curve: $\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})(1 + \cos(\frac{t}{T_{\max}} \pi))$. It starts with a warm exploratory rate ($5 \times 10^{-4}$) and gently anneals toward zero ($10^{-6}$), allowing the weights to settle into broad, flat local minima rather than sharp, brittle ones.
Math Q6: What is Label Smoothing Cross-Entropy and why is it used here?
Standard one-hot Cross-Entropy penalizes any output where $P(\text{correct}) < 1.0$, pushing model logit differences toward $\pm \infty$ and causing overconfidence.
Label smoothing replaces the hard target vector $y = [0, 0, 1, 0, 0, 0]$ with a softened distribution: $$y_k^{\text{smooth}} = (1 - \epsilon) y_k + \frac{\epsilon}{K}$$ With $\epsilon = 0.05$ and $K = 6$ classes, the true class receives $0.9583$ while all other classes receive $0.0083$. This prevents the classifier from becoming overly dogmatic on ambiguous gesture transitions.
Architecture Q7: Why not use a 3D Convolutional Network (3D-CNN / C3D / SlowFast)?
A 3D-CNN applies spatio-temporal convolutions across $(C, T, H, W)$ simultaneously. However:
1. Parameter & FLOP explosion: 3D kernels ($3 \times 3 \times 3$) require $3\times$ the parameters of 2D kernels per layer. A standard ResNet3D-18 has over 33 million parameters.
2. CPU Latency: In our deployment target (standard student laptop without an NVIDIA GPU), 3D-CNN inference takes over 250ms per forward pass, dropping webcam framerate below 4 FPS.
3. Our 2D-CNN + BiGRU architecture has only 1.9 million parameters (17× smaller), runs in 18ms on CPU, and reaches 30+ FPS live inference while achieving comparable gesture sequence modeling.
Pipeline Q8: How does the real-time webcam sliding buffer work?
The webcam captures incoming frames at ~30 FPS into a FIFO rolling queue (fixed length = 16). Every 130ms, the latest frame is preprocessed (resized to $112 \times 112$ and ImageNet standardized) and appended.
Before running neural inference, an inter-frame kinetic energy check computes average absolute pixel differencing: $\Delta = \frac{1}{T-1} \sum_{t=1}^{T-1} \text{mean}(|f_t - f_{t-1}|)$.
If $\Delta < 0.8$, the user is resting, and the system bypasses the neural forward pass entirely, conserving CPU and returning 'Resting / Idle'. When motion is active, the 16-frame tensor $(1, 16, 3, 112, 112)$ is evaluated, and an Exponential Moving Average ($P_{\text{smooth}} = 0.65 P_{\text{curr}} + 0.35 P_{\text{prev}}$) filters out transient noise.
Math Q9: How do you prevent vanishing or exploding gradients during training?
We use two complementary techniques:
1. Batch Normalization after every convolutional layer in the spatial extractor stabilizes internal covariate shift and keeps activations within healthy dynamic range.
2. Gradient Norm Clipping: In our training loop, we execute torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=2.0) immediately after loss.backward(). If the $L_2$ norm of the parameter gradients $\|\mathbf{g}\|_2 > 2.0$, gradients are scaled down proportionally: $\mathbf{g} \leftarrow \mathbf{g} \frac{2.0}{\|\mathbf{g}\|_2}$. This prevents catastrophic weight updates in recurrent GRU layers.
Integrity Q10: What are the primary failure cases and limitations of this system?
1. Domain Shift (Background & Illumination): The training dataset was recorded against a dark navy cloth background. In a room with bright white walls or backlight, raw pixel distributions shift, which we mitigate using a bounding ROI box and inter-frame motion gating.
2. Scale & Distance Sensitivity: If the user is seated too far from the camera, hand features occupy only a tiny fraction of the ROI, reducing feature activation.
3. Fine Finger Articulations: Distinguishing 'doctor' (two fingers on wrist) from 'pain' (claw-twist) requires high spatial clarity at $112 \times 112$ resolution.

Data Leakage & Validation Protocol Defense

The "100% Accuracy" Trap: If an examiner asks "Did your model get 100%?", answer firmly: "A naive random split produced an artificial 100% due to subject leakage. In academic deep learning, that is a known methodological error. We corrected it using strict Signer-Independent Group Splitting."

Why Naive Splitting Fails on Gesture Data

The Mendeley dataset consists of 26 signers ($S_{001} \dots S_{026}$), with each signer recorded twice per word ($T_1, T_2$). Both takes share:

  • Same person and face
  • Same clothing color and texture
  • Same background studio lighting
  • Same camera angle and skin reflection

When an algorithm randomly splits 80% train and 20% test: $$\mathbb{P}(S_i \in \text{Train} \land S_i \in \text{Test}) \approx 100\%$$ The network memorizes the background and clothing rather than true hand kinematics.

Our Scientifically Defensible Split Strategy

Dataset Partition Signers Included Clips Purpose
Training Set 17 Signers (Disjoint group) 268 clips Backpropagation gradient updates with AdamW
Validation Set 4 Signers (e.g., 001, 004, 009, 021) 64 clips Model checkpoint selection based on minimum validation loss
Held-Out Test Set 5 Signers (022, 023, 024, 025, 026) 80 clips Strict Zero-Shot evaluation on completely unseen individuals

5-Fold Signer-Independent Cross-Validation

Using sklearn.model_selection.GroupKFold(n_splits=5) grouped by subject_id, every signer is placed into the test fold exactly once across 5 independent training runs. The reported metric is the mean and standard deviation: $$\text{Accuracy} = \mu \pm \sigma \quad (\text{e.g., } 84.5\% \pm 5.2\%)$$ This satisfies the highest benchmark of empirical rigor expected in university evaluations.
